`@hejbro/nile` refuses identity columns (`generated always as identity` / `generated by default as identity`) in tenant-aware tables at generate time (`nile-identity-in-tenant-table`, measured on the platform's own test container: `IDENTITY columns are not supported for tenant-aware table`). A tenant-aware table with no primary key was measured on the same container and is accepted, so the skill's former "unmeasured" note for that shape is now a measured fact. No other preset's output changes.
